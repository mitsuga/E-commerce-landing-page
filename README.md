# 🛍️ ShopEase - eCommerce Landing Page

## 📌 Project Overview
ShopEase is a modern and responsive eCommerce landing page built using HTML and CSS. The website showcases featured products, promotional offers, and a newsletter subscription section with a clean and user-friendly design.

## ✨ Features
- Responsive Navigation Bar
- Hero Banner with Call-to-Action
- Featured Product Section
- Promotional Banner
- Newsletter Subscription Form
- Responsive Layout
- Hover Effects on Buttons and Product Cards
- Clean and Modern UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## 📁 Project Structure

```
ecommerce-landing-page/
│── index.html
│── style.css
│── README.md
```

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Learning Outcomes
- Building responsive web pages
- Creating modern layouts with Flexbox and Grid
- Styling websites using CSS
- Implementing hover effects and responsive design
